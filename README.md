# Tienda

Tienda web desarrollada con React, Vite y Tailwind CSS.

## Estructura

- `src/components/Header.jsx`
- `src/components/Inicio.jsx`
- `src/components/Productos.jsx`
- `src/components/Carrito.jsx`
- `src/components/Contacto.jsx`
- `src/components/Footer.jsx`
- `src/App.jsx`
- `src/main.jsx`
- `src/index.css`

## Características

- Componentes independientes.
- HTML semántico.
- Sin elementos `<div>`.
- Carrito básico con React state.
- Tailwind CSS directamente en los componentes.
- Estructura sencilla para aprendizaje.

## Ejecutar

```bash
npm install
npm run dev
```
